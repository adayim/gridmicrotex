# List loaded main (text) font families

Returns the names of main font families currently loaded by MicroTeX.
These can be used with
[`set_main_font`](https://adayim.github.io/gridmicrotex/reference/set_main_font.md).

## Usage

``` r
main_font_families()
```

## Value

A character vector of family names.

## Examples

``` r
main_font_families()
#> character(0)
```
